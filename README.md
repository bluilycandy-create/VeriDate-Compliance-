# VeriDate Compliance 🔍

> **Verify (驗證) + Date (日期) 的完美結合。**
> 專為食品加工、藥品製造或零售商設計的企業級效期與食安標示合規性稽核系統。

---

## 🌟 系統特色
- 💻 **免安裝與伺服器**：採用純前端 HTML5 + CSS3 + Vanilla JS 技術，直接雙擊 `index.html` 即可在任意瀏覽器運行，並可完美部署至 GitHub Pages。
- 🎨 **玻璃擬態暗色調設計 (Dark Glassmorphism)**：現代化 UI 設計、流暢的微動畫效果、精緻的霓虹外框與數據視覺化呈現。
- 📊 **多維度稽核圖表**：
  - 合規 vs 異常比例圓環圖。
  - 異常原因類型分布統計。
- 📂 **強大的資料解析與稽核**：
  - 支援將包含標示資料的 `.csv` 檔案直接拖曳上傳解析。
  - 內建一鍵「載入預設資料」按鈕，快速預覽功能。
- 🔍 **高效的篩選與搜尋**：
  - 提供批號與品項的即時模糊搜尋。
  - 提供多種分類標籤篩選（全部、合規、不合規、效期不符、資料缺失、重複上報）。
- 📥 **一鍵導出報告**：分析完成後可將含有詳細異常原因分析的稽核結果導出為全新的 CSV 檔案。

---

## 🛠️ 核心稽核規則
系統將對每筆資料執行以下五大合規稽核：
1. **欄位缺失檢查**：檢測「批號」、「品項」、「製造日期」或「實標效期」等欄位是否有空值。
2. **製造日期格式驗證**：支援並統一解析多種常見的製造日期格式，如：
   - `YYYYMMDD` (例：`20260202`)
   - `YYYY-MM-DD` / `YYYY/MM/DD` (例：`2026-03-03`、`2026/11/11`)
   - `D MMM YYYY` (例：`1 Feb 2026`)
   如果格式不符或無法解析，將標記為格式錯誤。
3. **效期匹配驗證**：比對「應標效期」與「實標效期」是否相符，若不相符則標記為「效期錯誤」。
4. **重複上載偵測**：檢測整筆資料是否與先前記錄完全重複，防止重複申報與統計誤差。
5. **合規率計算**：自動統計整體合規率百分比與分項異常計數。

## 🚀 快速啟動
1. **本機運行**：
   - 將此專案複製或下載至您的電腦。
   - 直接雙擊 [index.html](index.html) 檔案，即可在瀏覽器中開啟使用。
2. **GitHub Pages 部署 (可選)**：
   - 在本倉庫的 `Settings` -> `Pages` 中將 Source 設定為 `Deploy from a branch`。
   - 選擇 `main` 分支並點擊儲存，即可獲得一個線上公開的合規稽核工具網址！
